## Sobre

Projeto feito em 2023, no 2º ano do ensino médio técnico em Informática, em grupo de quatro alunos. O GEOTEC é um site educativo que reúne conteúdo de geografia física — topografia, geomorfologia, relevos e placas tectônicas — com textos, imagens, videoaulas e um quiz para fixar o conteúdo. É um front-end estático: as telas de login, cadastro e recuperação de senha são apenas interface, sem back-end.

## Funcionalidades

- Tela inicial com opção de entrar ou seguir como convidado.
- Telas de login, cadastro e recuperação de senha (somente interface).
- Páginas de conteúdo de Topografia, Geomorfologia, Relevos e Placas Tectônicas, com menu lateral e sumário por âncoras.
- Página de videoaulas com links para vídeos no YouTube, separados por tema.
- GeoQuiz em JavaScript: 12 perguntas de múltipla escolha, contador de acertos, aviso com a resposta correta ao errar e tela final com a pontuação.
- Página "Sobre nós" com os integrantes do grupo.

## Tecnologias

- HTML5
- CSS3 (uma folha por página, com variáveis de cor)
- JavaScript (quiz)

## Como executar

Abra `Edutec-main/index.html` no navegador. Não há dependências nem servidor.
